# Later releases (deferred until v0.2.2 gates pass)

These items are intentionally **not started** until Study Ready (v0.2.2) acceptance criteria pass. Criteria are summarized from the competitive roadmap.

## v0.3 — ExSim depth

Custom exam builder, pause/resume persistence, exports (HTML/JSON/CSV/PDF), ≥1000 CCNA / ≥800 ENCOR, meaningful PBQ/sim coverage, ENARSI only with a versioned map.

## v0.4 — NetSim depth

≥50 golden labs, broader OpenIOS matrix, expanded packet semantics, mature multi-device grading/reset/replay, catalog filters.

## v0.5 — Network Designer

Freeze lab schema v2 first; editable topology canvas; save/load user topologies; round-trip through `LabWorld`.

## v0.6 — Pack ecosystem

Curated GitHub pack index, verified manifests, install/update/remove UI, DMCA/content process.

## v1.0 — Competitive core

Authenticode + macOS/Linux packages, polished UX/a11y/support, signed updates, documented simulation scope.
